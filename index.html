Sekat adalah manajer partisi gratis untuk Windows 10 dan 11. Buat, ubah ukuran, pindahkan, salin, dan konversi partisi. Setiap perubahan masuk antrian dan langsung terlihat di peta disk, dan baru dijalankan saat Anda menekan Terapkan. Sekat is a free partition manager for Windows 10 and 11. Create, resize, move, copy, and convert partitions. Every change goes into a queue and shows up on the disk map right away, and nothing runs until you press Apply.

Cara kerjanyaHow it works

  1. 1

    Pilih partisiPick a partition

    Peta disk menampilkan semua disk, partisi, dan ruang kosong. Klik sebuah blok, atau klik kanan untuk melihat operasinya.The disk map shows every disk, partition, and free area. Click a block, or right-click it to see its operations.

  2. 2

    Susun antrianBuild a queue

    Setiap operasi disimulasikan dulu. Blok yang akan berubah ditandai kuning, jadi hasilnya terlihat sebelum disk disentuh.Each operation is simulated first. Blocks that will change are marked yellow, so you see the result before the disk is touched.

  3. 3

    TerapkanApply

    Sekat mencadangkan tabel partisi, lalu memindai ulang disk dan mencocokkannya dengan rencana sebelum setiap langkah.Sekat backs up the partition table, then rescans the disk and checks it against the plan before every step.

Baru di versi 1.1New in version 1.1

C: penuh, tapi partisi Recovery menghalangi?C: is full, but the Recovery partition is in the way?

Di banyak laptop, partisi Recovery terletak tepat setelah C:. Akibatnya Disk Management tidak bisa memperbesar C: walau ada ruang kosong di belakangnya. Sekat memindahkan partisi Recovery ke ujung disk lalu memperbesar C:, tanpa boot ke WinPE.On many laptops the Recovery partition sits right after C:, so Disk Management cannot extend C: even when there is free space behind it. Sekat moves the Recovery partition to the end of the disk and then extends C:, without booting into WinPE.

  1. reagentc /info memastikan WinRE aktif di partisi itu, lalu isinya diperiksa. Bila ada berkas lain, misalnya image pemulihan pabrik, Sekat berhenti sebelum mengubah apa pun.reagentc /info confirms WinRE is active on that partition, then its contents are checked. If there is anything else, such as a factory recovery image, Sekat stops before changing anything.
  2. WinRE dimatikan sebentar, dan winre.wim disimpan di C:.WinRE is turned off for a moment, and winre.wim is kept on C:.
  3. Partisi Recovery dibuat ulang di ujung disk dengan tipe dan atribut yang sama.The Recovery partition is recreated at the end of the disk with the same type and attributes.
  4. WinRE dinyalakan lagi di partisi baru, lalu C: diperbesar.WinRE is turned back on in the new partition, then C: is extended.

Lihat lebih dekatTake a closer look

Dibuat supaya sulit salahBuilt to be hard to get wrong

Disk fisik dikunciPhysical disks are locked

Secara bawaan hanya disk virtual (VHD/VHDX) yang bisa diubah. Kunci disk fisik dibuka dengan sengaja dari header.By default only virtual disks (VHD/VHDX) can be changed. You unlock physical disks on purpose from the header.

Windows dilindungiWindows is protected

Volume tempat Windows berjalan tidak bisa dihapus, diformat, atau diganti hurufnya. Partisi EFI dan MSR tidak pernah disentuh.The volume Windows runs from cannot be deleted, formatted, or given another letter. The EFI and MSR partitions are never touched.

Memakai API Windows sendiriUses Windows' own API

Operasi standar lewat Storage Management API, sama dengan Disk Management. Hanya pindah, salin, clone, dan pemulihan tabel yang menulis sektor sendiri, dan hanya ke disk yang sedang dilepas (offline).Standard operations go through the Storage Management API, the same one Disk Management uses. Only move, copy, clone, and table restore write sectors themselves, and only to a disk that is offline.

Diperiksa tiga kaliChecked three times

Isian divalidasi sebelum konfirmasi, divalidasi lagi setelah pindai ulang, lalu dicocokkan dengan data segar dari Windows tepat sebelum dijalankan.Input is validated before confirmation, again after a rescan, and once more against fresh data from Windows right before it runs.

Membaca tanpa hak adminReads without admin rights

Tanpa hak Administrator, Sekat hanya membaca. Disk dibuka tanpa akses tulis.Without administrator rights Sekat only reads. Disks are opened without write access.

Diuji di disk virtualTested on virtual disks

Setiap operasi tulis diuji otomatis di VHDX dalam 25 skenario, termasuk memastikan isi berkas tetap utuh.Every write operation is tested automatically on VHDX in 25 scenarios, including checks that file contents stay intact.

Mengubah partisi selalu punya risiko. Cadangkan data penting sebelum memindah, mengonversi, atau meng-clone disk. Changing partitions always carries some risk. Back up important data before moving, converting, or cloning a disk.

Juga dari terminalFrom the terminal, too

Semua yang ada di GUI juga ada di perintah sekat. Tulis beberapa operasi di satu file, lalu periksa dengan --dry-run: rencana dan peta hasilnya tampil tanpa hak Administrator. --json memberi data lengkap untuk skrip.Everything in the GUI is also in the sekat command. Write several operations into one file and check it with --dry-run: the plan and the resulting map are shown without administrator rights. --json gives complete data for scripts.

> sekat list
> sekat move 1 3 left
> sekat resize 1 3 max

# rencana.txtplan.txt

create 2 --size 1G --fs ntfs --label DATA
create 2 --fs exfat --label ARSIP

> sekat apply rencana.txtplan.txt --dry-run
> sekat apply rencana.txtplan.txt

Tanya jawabQuestions

Apakah Sekat gratis?Is Sekat free?

Ya. Sekat gratis dipakai untuk keperluan apa pun, dengan lisensi MIT atau Apache-2.0.Yes. Sekat is free to use for any purpose, under the MIT or Apache-2.0 license.

Kenapa disk saya tidak bisa diubah?Why can't I change my disk?

Ada dua kunci. Pertama, klik Jalankan sebagai Administrator di header. Kedua, disk fisik dikunci secara bawaan: klik Disk fisik terkunci di header untuk membukanya. Di CLI, tambahkan --allow-physical.There are two locks. First, click Run as Administrator in the header. Second, physical disks are locked by default: click Physical disks locked in the header to unlock them. In the CLI, add --allow-physical.

Bisakah saya mencoba tanpa risiko?Can I try it without any risk?

Bisa. Menu Disk virtual → Buat dan pasang VHDX uji membuat disk virtual untuk latihan. Semua operasi bisa dicoba di sana tanpa menyentuh disk asli.Yes. Virtual disk → Create and attach a test VHDX creates a virtual disk to practice on. You can try every operation there without touching a real disk.

Bagaimana bila listrik padam saat memindah partisi?What if the power goes out while moving a partition?

Buka Sekat lagi. Sebuah banner menawarkan Lanjutkan pemindahan, yang meneruskan dari potongan terakhir yang tercatat. Di CLI: sekat resume.Open Sekat again. A banner offers Resume move, which continues from the last recorded chunk. In the CLI: sekat resume.

Apa yang belum bisa dilakukan Sekat?What can't Sekat do yet?
  • Memindah partisi logical di disk MBR.Move logical partitions on MBR disks.
  • Memindah partisi data di disk tempat Windows berjalan, misalnya D:. Hanya partisi Recovery yang bisa dipindah di disk itu.Move data partitions on the disk Windows runs from, such as D:. Only the Recovery partition can be moved on that disk.
  • Clone atau image disk tempat Windows berjalan. Itu butuh mode WinPE, yang belum ada.Clone or image the disk Windows runs from. That needs a WinPE mode, which does not exist yet.
  • Mengubah ukuran volume selain NTFS dan ReFS. Ini batasan Windows sendiri.Resize volumes other than NTFS and ReFS. This is a limit of Windows itself.
  • Konversi ke MBR untuk disk dengan lebih dari 4 partisi.Convert a disk with more than 4 partitions to MBR.
Apakah Sekat mengirim data ke internet?Does Sekat send data anywhere?

Tidak. Sekat tidak terhubung ke internet sama sekali. Cadangan tabel partisi disimpan di %LOCALAPPDATA%\Sekat\backups.No. Sekat does not connect to the internet at all. Partition table backups are stored in %LOCALAPPDATA%\Sekat\backups.
