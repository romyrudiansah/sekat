Atur partisi Windows, lihat hasilnya sebelum disk diubah. Change Windows partitions and see the result before the disk is touched.

Sekat adalah manajer partisi gratis untuk Windows 10 dan 11. Setiap perubahan masuk antrian dan langsung tergambar di peta disk. Disk baru berubah saat Anda menekan Terapkan. Sekat is a free partition manager for Windows 10 and 11. Every change goes into a queue and shows up on the disk map right away. The disk only changes when you press Apply.

Antrian dulu, disk belakanganQueue first, disk later

  1. Peta diskThe disk map

    Sekat memindai semua disk, juga tanpa hak Administrator, lalu menggambar setiap partisi sebanding ukurannya.Sekat scans every disk, even without administrator rights, and draws each partition in proportion to its size.

    MSR E: DATA48 GiB kosongfree F: PROYEK40 GiB S: FOTO16 GiB

  2. Rencana di antrianThe plan in the queue

    Pindahkan PROYEK ke kiri lalu perbesar. Kedua langkah masuk antrian dan blok yang berubah ditandai kuning. Belum ada sektor yang ditulis.Move PROYEK to the left, then extend it. Both steps go into the queue and the changed block is marked yellow. No sector has been written yet.

    MSR E: DATA48 GiB F: PROYEK56 GiBdiubahchanged S: FOTO16 GiB

  3. TerapkanApply

    Sekat mencadangkan tabel partisi, lalu sebelum setiap langkah memindai ulang disk dan mencocokkannya dengan rencana. Bila ada yang tidak cocok, antrian berhenti di situ.Sekat backs up the partition table, then rescans the disk before every step and checks it against the plan. If something does not match, the queue stops right there.

    MSR E: DATA48 GiB F: PROYEK56 GiB S: FOTO16 GiB

Baru di versi 1.1New in version 1.1

C: penuh, tapi partisi Recovery menghalangiC: is full, but the Recovery partition is in the way

Di banyak laptop, partisi Recovery terletak tepat setelah C:, sehingga Disk Management tidak bisa memperbesar C: walau ada ruang kosong di belakangnya. Sekat memindahkan partisi Recovery ke ujung disk, lalu memperbesar C:. Semuanya selagi Windows berjalan, tanpa boot ke WinPE.On many laptops the Recovery partition sits right after C:, so Disk Management cannot extend C: even with free space behind it. Sekat moves the Recovery partition to the end of the disk, then extends C:. All of it while Windows runs, without booting into WinPE.

  1. reagentc /info memastikan WinRE aktif di partisi itu, lalu isinya diperiksa. Bila ada berkas lain, misalnya image pemulihan pabrik, Sekat berhenti sebelum mengubah apa pun.reagentc /info confirms WinRE is active on that partition, then its contents are checked. If anything else is there, such as a factory recovery image, Sekat stops before changing anything.
  2. WinRE dimatikan sebentar, dan winre.wim disimpan di C:.WinRE is turned off for a moment, and winre.wim is kept on C:.
  3. Partisi Recovery dibuat ulang di ujung disk dengan tipe dan atribut yang sama.The Recovery partition is recreated at the end of the disk with the same type and attributes.
  4. WinRE dinyalakan lagi di partisi baru, lalu C: diperbesar.WinRE is turned back on in the new partition, then C: is extended.

Pengaman yang sudah terpasangSafeguards built in

Mengubah partisi selalu punya risiko, jadi cadangkan data penting sebelum memindah, mengonversi, atau meng-clone disk. Di atas itu, Sekat memasang pengaman berikut.Changing partitions always carries some risk, so back up important data before moving, converting, or cloning a disk. On top of that, Sekat has these safeguards.

Disk fisik dikunciPhysical disks are locked
Secara bawaan hanya disk virtual (VHD/VHDX) yang bisa diubah. Kunci disk fisik dibuka dengan sengaja dari header.By default only virtual disks (VHD/VHDX) can be changed. You unlock physical disks on purpose from the header.
Windows dilindungiWindows is protected
Volume tempat Windows berjalan tidak bisa dihapus, diformat, atau diganti hurufnya, dan partisi EFI serta MSR tidak pernah disentuh.The volume Windows runs from cannot be deleted, formatted, or given another letter, and the EFI and MSR partitions are never touched.
Memakai API WindowsUses the Windows API
Operasi standar lewat Storage Management API, sama dengan Disk Management. Hanya pindah, salin, clone, dan pemulihan tabel yang menulis sektor sendiri, dan hanya ke disk yang sedang dilepas (offline).Standard operations go through the Storage Management API, the same one Disk Management uses. Only move, copy, clone, and table restore write sectors themselves, and only to a disk that is offline.
Diperiksa tiga kaliChecked three times
Isian divalidasi sebelum konfirmasi, divalidasi lagi setelah pindai ulang, lalu dicocokkan dengan data segar dari Windows tepat sebelum dijalankan.Input is validated before confirmation, again after a rescan, and once more against fresh data from Windows right before it runs.
Bisa dilanjutkan setelah listrik padamResumes after a power cut
Pemindahan partisi dicatat per potongan, jadi bila terputus Sekat bisa meneruskannya dari potongan terakhir.Partition moves are journaled chunk by chunk, so if one stops Sekat can continue from the last chunk.
Diuji di disk virtualTested on virtual disks
Setiap operasi tulis diuji otomatis di VHDX dalam 25 skenario, termasuk memastikan isi berkas tetap utuh.Every write operation is tested automatically on VHDX in 25 scenarios, including checks that file contents stay intact.

Dialog yang akan Anda temuiThe dialogs you will meet

Juga dari terminalFrom the terminal, too

Semua yang ada di GUI juga ada di perintah sekat. Tulis beberapa operasi di satu berkas, lalu periksa dengan --dry-run: rencana dan peta hasilnya tampil tanpa hak Administrator. Tambahkan --json untuk data lengkap bagi skrip.Everything in the GUI is also in the sekat command. Write several operations into one file and check it with --dry-run: the plan and the resulting map show up without administrator rights. Add --json for complete data for scripts.

> sekat list
> sekat move 1 3 left
> sekat resize 1 3 max

# rencana.txtplan.txt
init 2 --style gpt
create 2 --size 1G --fs ntfs --label DATA
create 2 --fs exfat --label ARSIP

> sekat apply rencana.txtplan.txt --dry-run
> sekat apply rencana.txtplan.txt

Tanya jawabQuestions

Kenapa disk saya tidak bisa diubah?Why can't I change my disk?

Ada dua kunci. Klik Jalankan sebagai Administrator di header, lalu buka kunci disk fisik dengan mengklik Disk fisik terkunci. Di CLI, tambahkan --allow-physical.There are two locks. Click Run as Administrator in the header, then unlock physical disks by clicking Physical disks locked. In the CLI, add --allow-physical.

Bisakah saya mencoba tanpa menyentuh disk asli?Can I try it without touching a real disk?

Bisa. Menu Disk virtual, lalu Buat dan pasang VHDX uji, membuat disk virtual untuk latihan. Semua operasi bisa dicoba di sana.Yes. Virtual disk, then Create and attach a test VHDX, creates a virtual disk to practice on. You can try every operation there.

Bagaimana bila listrik padam saat memindah partisi?What if the power goes out while moving a partition?

Buka Sekat lagi. Sebuah banner menawarkan Lanjutkan pemindahan, yang meneruskan dari potongan terakhir yang tercatat. Di CLI: sekat resume.Open Sekat again. A banner offers Resume move, which continues from the last recorded chunk. In the CLI: sekat resume.

Apa yang belum bisa dilakukan Sekat 1.1?What can't Sekat 1.1 do yet?
  • Memindah partisi logical di disk MBR.Move logical partitions on MBR disks.
  • Memindah partisi data di disk tempat Windows berjalan, misalnya D:. Di disk itu hanya partisi Recovery yang bisa dipindah.Move data partitions on the disk Windows runs from, such as D:. Only the Recovery partition can be moved on that disk.
  • Clone atau image disk tempat Windows berjalan.Clone or image the disk Windows runs from.
  • Mengubah ukuran volume selain NTFS dan ReFS; ini batasan Windows sendiri.Resize volumes other than NTFS and ReFS; this is a limit of Windows itself.
Apakah Sekat terhubung ke internet?Does Sekat connect to the internet?

Tidak sama sekali. Cadangan tabel partisi disimpan di %LOCALAPPDATA%\Sekat\backups di komputer Anda.Not at all. Partition table backups are stored in %LOCALAPPDATA%\Sekat\backups on your computer.

Ke mana saya melapor masalah atau mengusulkan fitur?Where do I report a problem or suggest a feature?

Tulis di Diskusi Sekat di GitHub (butuh akun GitHub gratis). Untuk laporan masalah, sebutkan versi Sekat, versi Windows, dan langkah yang Anda jalankan; hasil sekat list sangat membantu.Post in Sekat Discussions on GitHub (a free GitHub account is needed). For problem reports, include your Sekat version, Windows version, and the steps you ran; the output of sekat list helps a lot.
